# Week 26 logic

Policy gates run in a declared order: licence, language, quality, exact
duplicate, evaluation contamination, source cap, PII redaction and stable
document split. Vocabulary is fitted after splitting and only on accepted
training documents. Every sequence has a fixed length and attention mask.

The manifest hashes configuration and cleaned records. Reproducibility still
requires immutable raw snapshots, code/runtime versions and licensed source
provenance outside this in-memory example.
