# Week 30 logic

Packed weight memory is `parameters × bits / 8`. Worst-case KV memory per
request is `KV bytes per token × maximum context`. Requested memory adds a
declared non-weight budget and requested KV slots; this is an estimate, not an
allocator guarantee. Throughput and latency come only from supplied load
observations and remain labelled separately.

The report validator requires objective, dataset, training configuration,
compute, loss curve, evaluation, failures, cost, RAG comparison, lessons,
package and serving evidence. Schema completeness still needs human review of
truth, licensing, reproducibility and claims.
