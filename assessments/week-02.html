Your paper

Each paper contains two single-choice, two multiple-correct, two matching, two short syntax and two SQL coding questions. All ten questions are worth 10 marks each.

Scoring, coding and saved progress
  • Single-choice and short answers: 10 or 0. Multiple-correct: select the complete correct set for 10; no partial credit or negative marks.
  • Matching: 2.5 per correct pair; use each option once. Coding: 2 per passed check, with five checks per solution.
  • SQL runs on your device as PostgreSQL in WebAssembly using PGlite 0.5.11. Its runtime downloads when you run a solution. Each run uses a disposable browser worker with a 5-second execution limit after loading; Stop ends the worker.
  • Write one SELECT or WITH query, using the requested column names and result order. Five different datasets test values, duplicate rows, NULLs and date boundaries. Each dataset starts fresh, and your query runs in a read-only transaction. The schema and example data are available beside every coding question and on the printed paper.
  • The practice schema is smaller than the full lab and permits zero quantity to test denominator handling. This single-connection runtime does not reproduce the lab's two-session concurrency tests; those are assessed through reasoning questions.
  • If the runtime cannot load, coding marks remain pending. You can retry or open db<>fiddle with PostgreSQL 18, copy the schema and example data, and paste your query back here. Opening that link does not send your answers; external results do not sync automatically.
  • Progress and results stay in this browser. Download a result for review. The question bank and answer keys are public: this is a practice assessment, and downloaded scores are not authenticated exam records.
