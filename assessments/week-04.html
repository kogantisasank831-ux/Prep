Your paper

Each paper contains two single-choice, two multiple-correct, two matching, two short syntax and two Python coding questions. All ten questions are worth 10 marks each.

Coding tasks use Python’s standard library to check JSON keys, exact decimals, dates, labelled evidence and retry/repair logic. They use synthetic inputs; no model, server, API key or GPU is needed. These small helpers test their stated contracts. The full lab also applies Pydantic precision/scale rules and its complete extraction policy.

Scoring, coding and saved progress
  • Single-choice and short answers: 10 or 0. Multiple-correct: select the complete correct set for 10; no partial credit or negative marks.
  • Matching: 2.5 per correct pair; use each option once. Coding: 2 per passed check, with five checks per solution.
  • Python runs on your device in a separate browser worker using Pyodide. The runtime downloads when you run a solution. A run has a 5-second execution limit after loading; Stop ends its worker.
  • Keep solutions to the stated standard-library task. The full extraction lab and any real-model evaluation remain separate lesson exercises. If the runtime cannot load, coding marks remain pending. You can retry or use Google Colab (Google sign-in required), then paste your solution back here. Opening the link does not send your answers. External tool results do not sync automatically.
  • Progress and results stay in this browser. Download a result for review. The question bank and answer keys are public: this is a practice assessment, and downloaded scores are not authenticated exam records.
